Automatikus Számítási Segédlet az Aktuális Beállításokhoz

Ha fent átállítod az R1 (10k/100k), R3 (2k/10k), U_LSB (3,14V/6,28V) vagy Aktív/Passzív PI értékét, a levezetés azonnal frissül!

Alap + 2023 + iMSC képletek
1. Arányos erősítés (Ap)
Ap = R2 / R1 = 5,6k / 100k
0,056
2. Integrálási időállandó (Ti)
Ti = R2 · C = 5,6k · 33nF
184,8 µs
3. Fázisdetektor (K_PD)
K_PD = U_LSB / 2π = 6,28 / 2π
1 V/rad
4. VCO Meredekség (K_O)
K_O = R4 / (R3 · Uref · t_ms)
100 kHz/V
Töltésegyensúly levezetése (K_O-hoz):

Egy periódus alatt a bemeneti ellenálláson ($R_3$) befolyó töltés megegyezik a $t_{ms}$ impulzus alatt az $R_4$-en keresztül kivett töltéssel:

Uc / 2kΩ = (2,5V / 2,5kΩ) · 5µs · f
Hurokátvitel W₀(s) és f_max (2023-A/B):
Wc(s) = Ap · (1 + 1/(s·Ti))
Követési tartomány felső határa: f_max = 1 / t_ms = 200 kHz (mivel a kitöltési tényező nem lépheti át a 100%-ot!).
iMSC: Vágási körfrekvencia és Fázistartalék:
ω_c ≈ K_PD · Ap · K_O · 2π = 35,2 krad/s
φ_t = π/2 - arctan(1/(ω_c·Ti)) - ω_c·T_h ≈ 61°

(50%-os kitöltésnél T_h = 2·t_ms = 10 µs holtidővel számolva).
